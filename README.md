Gobble Dash: The Great Thanksgiving Escape — you are the turkey, dinner is at six, and the farmer has a carving knife. Run the farmyard, the barnyard and the kitchen, hide in hay bales, dodge thrown knives, stay out of the oven glow, eat corn for score and dash energy, and reach the Freedom Gate before your three feathers run out. The farmer patrols, chases, searches your last hiding spot and throws knives; the kitchen ovens roast a careless turkey. Keyboard (WASD/arrows, Space dash) and mouse (hold to steer, click to dash), with title, pause and caught/escaped end screens, WebAudio gobbles and a full HUD of score, distance, feathers and progress.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. The game is plain static files under game/ and also opens offline from game/index.html with no network request. Hand in with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
